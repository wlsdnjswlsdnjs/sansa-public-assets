# Sansa public assets

Public image and 3D model data used by [Sansa](https://sansatemple.com/).

Asset paths are preserved exactly. The `v/37821d4f60cfb916c0bd/` directory contains the frozen versioned asset set; `assets/` contains the public preview images, preview models and wordmark.

`MANIFEST.json` lists each asset's original decoded byte length, SHA-256 and media type. `MANIFEST.sha256` verifies that manifest. A data CDN can prefix a fixed immutable repository revision to the manifest paths.

## Credits and rights

`CREDITS.json` is the unchanged attribution document distributed with the public Sansa website. It also describes website assets outside this subset. Individual assets retain their existing authorship, licenses and attribution requirements. This distribution grants no additional license or rights.
