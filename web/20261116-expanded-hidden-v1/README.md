# Sansa compiled web modules

Compiled frontend modules for the public Sansa website. This web snapshot distributes compiled browser code for the website; it does not update installed store apps or contain private repository history.

The manifest records exact file bytes, SHA-256 and Subresource Integrity values. Worker scripts, stylesheets and fonts retain the official website origin. Credits and existing rights are described in ../../CREDITS.json; no additional license is granted.
